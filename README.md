## 📌 Overview

**LuminaLearn** is a web-based Smart Tuition Learning Management System (LMS) designed to digitalize and streamline academic and administrative operations of tuition institutions.

It replaces manual processes with a **centralized digital platform** for managing students, courses, attendance, payments, and communication.

---

## 🎯 Key Features

✨ Role-Based Access Control (Admin, Teacher, Student, Parent)  
📚 Course & Learning Material Management  
📝 Quiz & Assessment System  
📊 Attendance Tracking  
💰 Payment Status Monitoring (Paid / Due)  
🔔 Notification & Messaging System  
📈 Dashboard & Reports  

---

## 👥 User Roles

| Role     | Description |
|----------|------------|
| 👑 Admin | Manages users, payments, system data |
| 👨‍🏫 Teacher | Creates courses, quizzes, marks attendance |
| 🎓 Student | Accesses materials, attempts quizzes |
| 👨‍👩‍👧 Parent | Monitors attendance & payments |
